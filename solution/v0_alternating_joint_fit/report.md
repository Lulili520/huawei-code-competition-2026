# v0_alternating_joint_fit

## 本地结果

统一评测集包含 50 个 Linear 和 250 个 Attention case。单例按赛题公式计算 MSE 提升百分比，最终分为 300 个 case 的百分比总和。

| 指标 | 结果 |
|---|---:|
| Linear Output MSE | 5.690796e-3 |
| Attention Output MSE | 3.786237e-4 |
| 最终得分 | **16407.289266** |
| 本地评测耗时 | 685.727 s |
| 格式检查 | 22/22 通过 |

## 核心设计

### 问题与修改方向

一次性 Linear 拟合先固定激活量化，再修复权重。权重发生变化后，原先的激活重要性可能不再匹配新的权重，导致激活量化和权重量化各自合理、组合起来却不是最优。

本版本在校准阶段交替执行两类动作：先按照当前激活编码拟合输出感知权重，再根据拟合后权重的列能量重新估计激活通道重要性。完成两轮后，把最后一次重要性写入在线激活状态。Attention 路径保持与 `v0_hessian_repair` 相同。

### 主要超参数

| 参数 | 取值 | 含义 |
|---|---:|---|
| `_ALTERNATING_ROUNDS` | `2` | 激活编码与权重拟合的交替轮数 |
| `_OUTPUT_AWARE_DAMPING` | `0.01` | 最小二乘拟合的相对阻尼 |
| `_OUTPUT_AWARE_MAX_ROWS` | `2048` | 参与输出感知拟合的最大校准行数 |
| `_BLOCK` | `64` | 权重拟合和 HiF4 一级处理宽度 |
| importance 范围 | `[1/16, 16]` | 防止少量极端通道支配激活 scale 搜索 |

本轮只有主配置完成评测，因此无法证明两轮、阻尼或裁剪范围分别是最优值。

## 结果分析

相对 `v0_hessian_repair`：

- Linear MSE 从 `5.876366e-3` 降至 `5.690796e-3`，降低约 **3.158%**。
- Attention MSE 完全相同，符合 Attention 路径未修改的预期。
- 最终得分增加 `23.777859`，相对提高约 **0.145%**。

结果支持交替联合拟合能够改善当前 300 例的 Linear 输出，但总分增益较小，因为评测集中 Attention case 占五倍权重。没有逐轮目标与模块消融，尚不能证明列能量更新是收益的唯一来源。

## Take Away

- Linear 中的激活量化和权重量化是耦合问题，交替更新比固定一侧后只拟合一次更合理。
- 该版本是当前三个保留版本中的本地 Linear MSE 最优版本。
- 本地评测耗时超过五分钟，且综合收益小于 Attention 路线；适合作为 Linear 专项研究基线，而不是当前综合提交首选。
