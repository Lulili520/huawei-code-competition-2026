# v22_reciprocal_consumer_stack 优化策略

## 基准版本

- **比较基准**：`v6_softmax_trust_region_repair`。
- **已验证事实**：基准在正式 300 例（50 Linear、250 Attention）上的综合分为 `16559.315496760442`，Linear MSE 为 `0.005876365662724178`，Attention MSE 为 `0.00037548714921267724`。
- **选择原因**：它是精简后现有版本中分数最高且带完整评测记录的版本，因此适合衡量新方案是否真正越过当前瓶颈。

## 实现基础

- **实现来源**：`scratch`。
- 本版本导入用户提供的 `reference/solution.zip` 中独立算法，不继承 `v6` 的代码。`based_on=v6_softmax_trust_region_repair` 只表示实验对照关系。
- **已验证事实**：压缩包 SHA-256 为 `F8D7847AC36B4BC6F34CC7A89839FCCB7984A407CC87546F7B64C5AA9FA799A0`；其中只有一个 `solution.py`。导入后必须再次校验目标文件哈希并完成官方格式自检。

## 固定输入边界

- NVFP4 反量化严格保持为：E2M1 数值乘输入提供的 E4M3 scale，每 16 个连续值共享一个 scale，然后恢复原 shape。
- 不重新估计 NVFP4 scale，不改变 scale 对应关系和 16 值分组。
- HiF4 输出必须使用规定的 64 值层级结构、合法 E6M2 外层 scale、LV2/LV3 以及合法尾数量化值。
- 仅使用 CPU；正式评测仍是固定 50 个 Linear 与 250 个 Attention 样例，综合权重为 Linear : Attention = 1 : 5。

## 问题分析

### 1. 张量 MSE 与赛题输出误差不完全一致

- **已验证事实**：赛题评价的是 Linear 输出或 Attention 输出，而不是某个中间张量自身的重建误差。
- **理论推导**：Linear 中权重误差 `ΔW` 的影响近似为 `X·ΔWᵀ`，因此同样大小的 `ΔW` 在高能量输入方向上会造成更大输出误差。Attention 的 V 误差则被概率矩阵 `P` 加权，主要风险近似为 `ΔVᵀPᵀPΔV`。
- **待验证假设**：直接按消费者敏感度选择合法离散码，比只最小化张量 MSE 更贴合最终得分。

### 2. Q/K 可在不改变原始注意力 logits 的前提下重新分配动态范围

- **理论推导**：对任意可逆矩阵 `T`，令 `Q'=QT`、`K'=KT^{-T}`，则 `Q'K'ᵀ=QKᵀ`。量化前用互逆变换把 Q/K 放到更适合 HiF4 网格的坐标系，可降低量化后的误差，而浮点目标保持不变。
- **待验证假设**：由 Q/K 公共统计量构造的协方差平衡变换与共同排列，能同时减少离群方向和块内尺度冲突。

### 3. Softmax 有可利用的零空间

- **理论推导**：Softmax 对每行加同一个常数不变，即 `softmax(z+c·1)=softmax(z)`；同时其每行概率和恒为 1。因此，logit 的行常数误差不是有效输出误差，应在中心化空间评估 Q/K 修复。
- **待验证假设**：K 的 token-common gauge 修复与中心化 Hessian 能把有限 HiF4 码字优先用于真正影响概率分布的误差方向。

### 4. 当前高分实现的主要代价是计算复杂度

- **已验证事实**：对压缩包内容进行同一 60 例筛选时，它以 `4265.940162` 对 `3241.543985` 胜过 `v6`，但耗时约 `242.9 s` 对 `140.5 s`；初次完整 300 例检查耗时约 `1148.8 s`，约为 `v6` 的 `2.06` 倍。
- **问题定位**：方案串联了多轮离散坐标搜索、跨块修复和 V 的多种消费者修复。它适合作为高精度教师，但还不适合作为最终的简洁高效实现。

## 相关方案调研

- **GPTQ**：Elias Frantar 等，*GPTQ: Accurate Post-Training Quantization for Generative Pre-trained Transformers*，2022，[论文](https://arxiv.org/abs/2210.17323)。其核心启发是用二阶信息衡量权重量化对输出的影响；本版本只借鉴“输出敏感度/Hessian”思想，不改变赛题格式。
- **SmoothQuant**：Guangxuan Xiao 等，*SmoothQuant: Accurate and Efficient Post-Training Quantization for Large Language Models*，2022，[论文](https://arxiv.org/abs/2211.10438)。它通过数学等价缩放在权重与激活之间迁移量化难度；本版本把同类等价变换用于 Linear 和 Q/K。
- **QuaRot**：Saleh Ashkboos 等，*QuaRot: Outlier-Free 4-Bit Inference in Rotated LLMs*，2024，[论文](https://arxiv.org/abs/2404.00456)。它说明保持计算等价的旋转可削弱离群值；本版本使用由任务统计量得到的互逆变换，而不是直接照搬随机 Hadamard 旋转。
- **项目内证据**：提供方案还包含固定码域中的坐标下降、Softmax 平移零空间处理以及 `PᵀP` 加权的 V 修复。这些属于待通过本地消融归因的组合策略，不能仅凭最终总分断言每个模块都有效。

## 理论分析

完整因果链如下：

1. **问题证据**：`v6` 的 Linear 与 Attention MSE 仍分别为 `0.005876...` 和 `0.000375...`，而张量误差代理不能完全解释最终输出误差。
2. **理论依据**：等价变换可在不改变浮点输出的条件下重排动态范围；Hessian 或消费者 Gram 矩阵可把误差投影到最终输出敏感方向；Softmax 行平移方向可被剔除。
3. **算法动作**：先做 Linear 逆缩放和 Q/K 互逆基变换，再在合法 HiF4 离散码域内执行输出风险驱动的修复；V 使用 `PᵀP` 近似其消费者风险。
4. **目标指标**：完整 300 例综合分高于 `16559.315496760442`，且 Linear、Attention MSE 均低于基准。
5. **否证条件**：若正式得分不高于基准，或任一主任务 MSE 没有下降，则“组合结构能同时改善两类任务”的假设被否证。即使总分改善，缺少模块消融时，各子模块的独立贡献仍记为“证据不足”。

## 选定修改方案

### 核心算法

1. **Linear 等价预条件**：用成对逆缩放重新分配权重与激活动态范围，保持浮点矩阵乘结果不变。
2. **Linear 输出风险修复**：用激活二阶矩和输出中心映射指导 GPTQ/坐标下降，只在合法 HiF4 码字中选择候选。
3. **Q/K 公共谱坐标系**：从两者统计量构造互逆变换和共同排列；变换前后浮点 `QKᵀ` 理论上保持不变。
4. **Softmax-aware Q/K 修复**：在去除每行常数方向后评价候选，并用 K 的 token-common gauge 吸收不影响 Softmax 的误差。
5. **V 消费者加权修复**：用 `PᵀP` 近似输出风险，并组合局部链、全局直流和低秩方向的合法离散修复。
6. **安全回退**：所有搜索都保留基准量化候选；候选未改善目标代理时回退，避免无条件接受复杂修复。

### 修改目标

- 首要目标：正式综合分超过 `20000`，并高于 `v6`。
- 定位目标：同时降低 Linear MSE 与 Attention MSE。
- 工程目标：把本版本固化为后续消融和加速的高精度教师，而不是直接宣称其每个子模块都必要。

### 修改范围

- 仅修改 HiF4 参数生成与合法离散候选的选择策略。
- 允许在校准阶段计算二阶统计量、互逆变换和消费者风险。
- 不改变评测器、样例、评分公式或输入 NVFP4 反量化。

### 保持不变

- NVFP4 的值语义、输入 scale、16 值分组和 shape 恢复方式。
- HiF4 输出接口和合法编码集合。
- 5:25 的正式样例结构及 Linear : Attention = 1 : 5 的计分权重。

## 算法内部超参数计划

本轮目标是先忠实复现提供方案，因此只设一个主配置，不因参数变化创建新版本：

| 参数 | 主值 | 含义与依据 |
|---|---:|---|
| Attention 平衡指数 | `0.625` | 控制 Q/K 动态范围迁移强度；沿用提供方案，待后续消融而非本轮调参 |
| Q/K 宽窗口搜索步数 | `24` | 在固定 scale 下扩大合法码字搜索邻域 |
| Linear 输出码下降步数 | `16` | 在输出风险代理下迭代改进合法离散码 |
| V 低秩修复秩 | `4` | 捕获 `PᵀP` 中少量主要消费者方向，控制计算量 |
| Q/K 互逆变换与共同排列 | `开启` | 本版本核心结构，不作为调参项 |
| V Nyström 分支 | `关闭` | 提供方案中为关闭状态，不把未启用消融分支计作有效策略 |

若正式复现通过，下一轮只进行算法族级消融，不以 alpha、步数或阈值微调建立新版本。
