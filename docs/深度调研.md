# NVFP4 → HiF4 深度调研

> 项目：2026 华为算法大赛初赛 - 高精度 4Bit 数值转换算法
> 调研时间：2026-08-31
> 范围：NVFP4、HiF4、Linear 二阶量化、Attention Q/K/V 量化与等价变换

## 1. 调研问题

比赛给出的参考值不是模型最初的 FP16/FP32 张量，而是 NVFP4 数据按照固定规则反量化后的 BF16 值。参赛算法需要把这些值重新编码成合法 HiF4 参数，并尽可能保持 Linear 和 Attention 的计算结果。

因此，本题与普通“把高精度模型压成 4 bit”不同。源数据已经经历一次 NVFP4 量化，算法只能减少第二次格式转换新增的误差，不能恢复 NVFP4 已经丢失的信息。

```text
NVFP4 参数
    ↓ 固定反量化
BF16 参考张量
    ↓ 选择合法 HiF4 参数
HiF4 重构张量
    ↓
比较 Linear / Attention 输出误差
```

调研主要回答三个问题：NVFP4 与 HiF4 的结构差异为什么导致转换误差；Linear 中为什么 Hessian/GPTQ 比普通 Tensor MSE 更合理；Attention 中为什么 Q/K 公共基底、互逆缩放和对侧协方差可能有效。

## 2. NVFP4 与 HiF4 的格式差异

NVFP4 和 HiF4 都不是单独一种 4-bit 元素格式，而是“4-bit 元素 + 分组共享缩放元数据”的微缩放体系。两者平均都约为 4.5 bit/value，但表示精度的分配方式不同。

| 特征 | NVFP4 | HiF4 |
|---|---|---|
| 元素格式 | E2M1 | S1P2（论文也称 E1M2） |
| 元素非负码值 | 0、0.5、1、1.5、2、3、4、6 | 0～1.75，步长 0.25 |
| 基本分组 | 16 元素 | 64 元素 |
| 共享尺度 | E4M3 per-16，另有 FP32 tensor scale | E6M2 per-64，加两层二值微指数 |
| 平均存储 | 约 4.5 bit/value | 4.5 bit/value |
| 主要特点 | 小分组、局部 scale 精细 | 大分组、元素精度更高、树状局部 scale |

### 2.1 NVFP4

NVFP4 的 4-bit 元素使用 E2M1。每 16 个元素共享一个 E4M3 scale，整个 Tensor 还可以共享一个 FP32 全局 scale。完整解码关系为：

$$
\hat x_i=q_i\,s_{block}\,s_{tensor}
$$

NVIDIA 官方 direct-cast 的基本思路是：先由全 Tensor 最大值确定全局尺度，再由每 16 元素最大值确定 E4M3 block scale，最后把归一化元素舍入到 E2M1。由于 block scale 本身还要量化为 E4M3，direct-cast 的实际尺度并不总是连续空间中的最优尺度。

NVFP4 的训练 recipe 还可能包含随机 Hadamard 变换、二维缩放、梯度随机舍入和选择性高精度层。这些属于完整训练方法，不是 NVFP4 基础格式或本赛题反量化公式的一部分。

### 2.2 HiF4

HiF4 每 64 个元素构成一个单元：64×4 bit 元素加 32 bit 缩放元数据，总计 288 bit，即 4.5 bit/value。元素使用 S1P2，非负幅值为：

```text
0, 0.25, 0.5, 0.75, 1, 1.25, 1.5, 1.75
```

64 元素共享一个 E6M2 基础尺度；每 8 元素有一个二级微指数，每 4 元素有一个三级微指数。两个微指数都只能选择 0 或 1，即分别乘以 1 或 2：

$$
\hat x_i=s_{E6M2}\,2^{e_{8,i}+e_{4,i}}\,q_i
$$

S1P2 最大幅值 1.75，再乘两级最大微尺度 2×2，局部最大幅值为 7。官方转换流程因此围绕“64 元素全局最大值、8 元素局部最大值、4 元素局部最大值”逐级生成 scale，最后舍入 S1P2。

### 2.3 转换为什么不是简单查表

NVFP4 的四个 16 元素 block 合并成一个 HiF4 64 元素 block 后，原来的四个 E4M3 scale 不能直接复制到一个 E6M2 和两级微指数中。HiF4 的一个基础 scale 同时影响 64 个数，lv2 影响 8 个数，lv3 影响 4 个数，因此尺度选择与元素舍入是耦合的组合问题。

逐元素最近舍入只能在尺度已固定时局部最优，不能保证整个 64 元素 block 最优。由最大值决定 scale 主要保证不溢出，也不等价于最小重构误差，更不等价于最小 Linear 或 Attention 输出误差。

## 3. Linear：从 Tensor MSE 到输出误差

设线性层输出为 $Y=XW^T$，量化权重为 $\hat W$，权重误差为 $D=W-\hat W$。输出误差为：

$$
\|XD^T\|_F^2=\sum_r d_r^T(X^TX)d_r
$$

这说明权重中相同大小的误差，在不同输入方向上代价不同。普通权重 MSE 相当于使用单位矩阵衡量误差，而真实 Linear 输出误差由校准 Activation 的二阶统计 $H=X^TX$ 决定。

### 3.1 OBQ 与 GPTQ

Optimal Brain Compression（OBC/OBQ）把量化写成二阶优化问题。某个权重被固定到量化值后，舍入残差不是直接丢弃，而是按照逆 Hessian 分配到尚未量化的自由变量，使校准输出尽量保持不变。

GPTQ 延续这一思想，但采用固定列顺序、共享 Hessian、阻尼、Cholesky 分解和批量延迟更新，使大模型的一次性权重量化具备可扩展性。它的核心不是“补偿项乘 2”，也不是算法规定必须执行两遍。

迁移到本题时，Hessian 目标仍然成立，但 HiF4 不是相互独立的标量量化：一个 block 内的 E6M2、lv2、lv3 和 mant 彼此耦合。因此更准确的理解是，GPTQ 可以给合法 HiF4 候选提供二阶评价和残差传播，但不能把原论文中的独立标量舍入原样复制过来。

### 3.2 SmoothQuant 与 AWQ

SmoothQuant 使用成对的逐通道缩放，把 Activation 的量化难度迁移到 Weight：

$$
X'=X\,diag(s)^{-1},\qquad W'=W\,diag(s)
$$

在浮点下有 $X'W'^T=XW^T$。这种等价预条件可以降低 Activation 离群通道对共享 scale 的影响。

AWQ 同样利用 Activation 统计识别重要权重通道，并通过成对缩放保护这些通道。两者共同说明：重要性不能只由 Weight 自身的幅值判断，输入分布决定了权重误差对输出的影响。

不过，SmoothQuant 原本面向 W8A8，AWQ 原本面向 weight-only INT4。它们对 HiF4 的价值是“等价缩放和重要通道保护”的思想，而不是论文中的精度数字可以直接复现。只有缩放与逆缩放都能合法保留时，浮点函数才保持不变。

### 3.3 Linear 方法的适用边界

二阶方法可以减少 NVFP4→HiF4 的新增误差，但不能恢复 NVFP4 中已经丢失的原始权重。有限校准样本还可能使 Hessian 病态或过拟合，通常需要阻尼。GPTQ 的处理顺序、block 边界以及补偿后再次进行 HiF4 投影，也会使理论上的二次型下降不一定完全转化为平台得分提升。

## 4. Attention：Q、K、V 的误差传播不同

Attention 的基本形式为：

$$
L=QK^T/\sqrt d,\qquad P=softmax(L),\qquad O=PV
$$

如果 $\hat Q=Q+E_Q$、$\hat K=K+E_K$，则 logits 误差为：

$$
\Delta L=E_QK^T+QE_K^T+E_QE_K^T
$$

因此 Q 的误差由 K 的方向和能量加权，K 的误差由 Q 加权。分别最小化 Q-MSE 和 K-MSE，并不等价于最小化 logits 误差。

V 的误差则通过：

$$
\Delta O=P(\hat V-V)
$$

传递到输出。被高 Attention 权重访问的 token 更重要，普通 V Tensor MSE 也不能完全代表 Attention 输出误差。KIVI 的论文实验显示，K/V 选择不同量化粒度时，张量重构误差和最终 Attention 误差的排序可能明显不同。

## 5. 公共谱基底为什么可能有效

### 5.1 浮点计算保持不变

对任意正交矩阵 $R$：

$$
Q'=QR,\qquad K'=KR
$$

则：

$$
Q'K'^T=QRR^TK^T=QK^T
$$

更一般地，对可逆矩阵 $R$，使用 $Q'=QR$、$K'=KR^{-T}$ 也保持乘积不变。这提供了一族浮点等价的 Q/K 表示。

### 5.2 HiF4 对坐标系敏感

HiF4 固定每 64 元素分组，并在 64/8/4 层级共享尺度，因此它不是旋转不变量。同一个向量在不同坐标系中可能具有完全不同的 block 最大值、离群值位置和 scale 利用率。

公共谱基底可由 Q/K 联合二阶统计构造，例如：

$$
C=Q^TQ+K^TK,\qquad C=R\Lambda R^T
$$

在新基底中，相关方向被解耦，主要能量方向被重新排列，离群能量也可能分散到更多通道。它不是截断 PCA，不删除维度；作用只是从浮点等价表示中选择更适合固定 block 和共享 scale 的坐标系。

Q、K 不能各自独立做 PCA。若使用不同的 $R_Q$ 和 $R_K$，通常有 $R_QR_K^T\neq I$，会直接改变 logits。公共基底有效的前提正是两侧严格匹配。

### 5.3 旋转相关研究

QuaRot 使用计算不变的 Hadamard 旋转平滑离群值，并展示了 W4A4KV4 的可行性。SpinQuant 进一步指出不同旋转的量化效果差异很大，通过学习正交旋转提高量化精度。这些工作支持“等价旋转可以改变低比特量化难度”，但其 INT4 结果不能直接当成 HiF4 的比赛收益。

DuQuant 使用 block-wise rotation、通道置换和再次旋转，把 massive outlier 分散到多个 block；RPTQ 根据通道范围聚类并重排。它们与 HiF4 的关联在于：即使全局方差不变，只要降低同一 64 元素 block 内的动态范围差异，共享 scale 的有效精度就可能提高。

### 5.4 对角互逆缩放

QServe/SmoothAttention 使用 Q/K 互逆逐通道缩放，把 K 的离群通道量化难度迁移到 Q：

$$
(Q\Lambda)(K\Lambda^{-1})^T=QK^T
$$

这与参考提交中的 Q/K smooth scale 高度相似。对角缩放比全旋转成本更低、数值更稳定，但本题中 Q 和 K 都需要量化，不能只降低 K 的误差而无限放大 Q，必须同时考虑两侧的量化结果。

### 5.5 公共基底的限制

联合协方差的特征向量只对角化二阶统计，并不直接最小化离散 HiF4 编码后的 Attention loss。特征值接近时，特征向量还可能不稳定。非正交变换虽然保持乘积，但条件数过大可能把动态范围从一侧转移到另一侧并放大量化噪声，因此 Q/K 都量化时，正交或近正交变换通常更稳健。

RoPE 也是重要边界：如果旋转直接施加在 Post-RoPE 的 Q/K 上，内积恒等容易成立；如果试图提前融合到投影权重，变换必须与 RoPE 可交换。GQA 中多个 Q head 共用一个 K head，联合统计应汇总对应 Q 组的二阶贡献，而不是先对原始 Q 求均值，否则可能发生正负抵消。

## 6. K/V 量化研究带来的认识

KIVI 观察到 K 的离群值更倾向于固定在通道维，因此采用 K per-channel、V per-token 的不同粒度。KVQuant 也强调 K 的通道离群值、层敏感度和异常值处理。这些论文研究的是 KV Cache，其系统吞吐数字不能直接迁移到本赛题，但其分布观察解释了为什么 K 更适合由 Q 的全协方差衡量，而 V 更需要关注 Attention 权重。

赛题的 HiF4 格式和 block 边界固定，通常不能照搬 per-channel/per-token 数据类型，也不能额外保存稀疏高精度 outlier。可以直接继承的是误差分析：Q/K 应看 logits 或 Attention 输出，V 应看 $P\Delta V$，Tensor MSE 只能作为辅助指标。

## 7. 方法与本赛题的关系

| 方法 | 原始目标 | 对本题有价值的思想 | 不能直接照搬的部分 |
|---|---|---|---|
| GPTQ / OBQ | 权重量化 | Hessian 输出误差、残差补偿 | 独立标量量化假设 |
| SmoothQuant | W8A8 | 成对互逆缩放、平滑离群值 | INT8 结论与相邻层折叠方式 |
| AWQ | INT4 weight-only | Activation 感知的重要通道 | 原论文码本和精度结果 |
| QuaRot | W4A4KV4 | 正交旋转保持函数、平滑离群值 | Hadamard 不一定最适合 HiF4 |
| SpinQuant | 学习旋转 | 旋转选择决定量化效果 | 训练成本和原量化目标 |
| QServe | 低比特推理 | Q/K 对角互逆平滑 | 原方法主要保护 K |
| KIVI / KVQuant | KV Cache | K/V 分布差异与输出敏感度 | 缓存粒度和系统加速数字 |
| DuQuant / RPTQ | 激活量化 | 重排能改善 block 内范围 | 变换必须可被合法抵消 |

整体上，相关研究可以归纳为两层。格式层负责生成严格合法的 HiF4 参数并控制 block 重构误差；计算层利用 Linear Hessian、Q/K 等价变换和 Attention 误差传播，判断哪些合法编码对最终输出更重要。两层目标相关但并不等价。

## 8. 结论

NVFP4→HiF4 的困难来自两种微缩放结构不一致：16 元素 E4M3 scale 必须重新组织为 64/8/4 的 HiF4 树状尺度。由于共享 scale，一个元素或局部离群值会影响同组其他元素，转换本质上是带格式约束的组合量化问题。

Linear 中，$X^TX$ 决定权重量化误差对输出的影响，解释了 Hessian/GPTQ、Activation 感知缩放为什么比单纯 Weight MSE 更有依据。Attention 中，Q/K 的误差由对侧张量加权，V 的误差由 Attention 权重加权，因此三个张量不应使用完全相同的误差代理。

公共谱基底的价值不在 PCA 本身，而在利用 Q/K 的正交不变性：浮点 $QK^T$ 保持不变，但能量和离群值被重新组织到更适合 HiF4 固定 block 与共享 scale 的坐标系。它具有明确的数学依据，也受到 QuaRot、SpinQuant 等旋转量化工作的支持；但它是否优于恒等基底，最终仍由具体 HiF4 编码后的 Attention 输出误差决定。
